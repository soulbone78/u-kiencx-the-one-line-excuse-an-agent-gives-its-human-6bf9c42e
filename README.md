# The One-Line Excuse an Agent Gives Its Human

Entry for the make.fun bounty
`u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e` ($5).

`main.py` (pure Python standard library) writes one original line —
the excuse an AI agent hands its human after missing a deadline —
to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
